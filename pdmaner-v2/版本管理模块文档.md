# 版本管理模块文档

## 功能描述
- 实现表结构版本控制系统
- 支持增量DDL脚本生成
- 提供版本差异可视化对比

## 代码架构
```bash
代码入口：src/lib/datasource_version_util.js
页面组件：src/components/versionListBar
关联模块：数据表管理、ER关系图
```

## 核心功能点
1. 版本控制
   - 自动创建版本快照
   - 语义化版本号管理
   ```js
   // 版本元数据示例
   const versionMeta = {
     version: "2.1.0",
     changes: [
       {type: "ADD", object: "Table:User"},
       {type: "MODIFY", object: "Field:User.email"}
     ]
   }
   ```

2. 差异分析
   - 结构变化自动检测
   - 智能冲突解决建议
   ```mermaid
   graph LR
     A[当前版本] --> B{版本对比}
     C[历史版本] --> B
     B --> D[生成差异报告]
   ```

3. 版本操作
   - 一键回滚机制
   - 分支版本管理
   - 合并冲突解决

## 接口定义
```typescript
interface VersionService {
  createVersion(comment: string): Promise<Version>;
  compareVersions(v1: string, v2: string): Promise<DiffResult>;
  rollback(version: string): Promise<void>;
}
```

## 关联组件
1. VersionTimeline - 版本时间轴
2. DiffViewer - 差异可视化查看器
3. ConflictResolver - 冲突解决向导
4. SnapshotManager - 快照管理工具

## 操作流程
1. 创建版本快照
2. 查看版本历史
3. 对比版本差异
4. 执行版本回滚
5. 解决合并冲突
