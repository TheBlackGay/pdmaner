# 代码生成模块文档

## 功能描述
- 支持多语言代码模板生成
- 实现动态模板引擎渲染
- 提供代码风格统一管理

## 代码架构
```bash
代码入口：src/lib/generatefile
页面组件：src/components/codeeditor
关联模块：模板管理、数据表管理
```

## 核心功能点
1. 模板引擎
   - 支持Velocity/FreeMarker语法
   - 动态变量注入
   ```js
   // 代码生成配置示例
   const templateConfig = {
     language: 'Java',
     package: 'com.example.model',
     include: ['getter', 'setter', 'toString']
   }
   ```

2. 代码优化
   - 自动格式化
   - 导入包整理
   ```mermaid
   graph TB
     A[原始代码] --> B{代码规范检查}
     B -->|通过| C[生成最终代码]
     B -->|未通过| D[提示优化建议]
   ```

3. 版本控制
   - 生成代码版本追溯
   - 差异对比功能
   - 历史版本回滚

## 接口定义
```typescript
interface CodegenService {
  generateFromTemplate(templateId: string, data: object): Promise<string>;
  validateCode(code: string): ValidationResult;
  getHistoryVersions(entity: string): Promise<CodeVersion[]>;
}
```

## 关联组件
1. TemplateEditor - 代码模板编辑器
2. CodePreview - 实时代码预览器
3. StyleConfig - 代码风格配置器
4. VersionDiff - 代码版本差异对比

## 操作流程
1. 选择数据表或实体
2. 配置生成参数
3. 选择代码模板
4. 预览生成结果
5. 导出或直接保存代码
