# 多数据库支持模块

## 功能描述
- 实现异构数据库的统一接入管理
- 提供数据库方言自动适配
- 支持跨数据库结构迁移

## 代码架构
```bash
代码入口：src/lib/datasource_util.js
页面组件：src/components/select
关联模块：数据表管理、代码生成
```

## 核心功能点
1. 数据库适配
   - 自动识别数据库类型
   - 方言转换引擎
   ```js
   // 数据库配置示例
   const dbConfig = {
     type: 'mysql',
     host: 'localhost',
     port: 3306,
     dialectOptions: {
       charset: 'utf8mb4'
     }
   }
   ```

2. 结构迁移
   - 自动生成DDL转换脚本
   - 数据类型映射转换
   ```mermaid
   graph LR
     A[源数据库] --> B{类型映射}
     B --> C[目标数据库]
     C --> D[执行转换]
   ```

3. 统一接口
   - 标准化查询接口
   - 事务管理抽象层
   - 连接池统一管理

## 接口定义
```typescript
interface DatabaseService {
  connect(config: DBConfig): Promise<Connection>;
  migrateSchema(source: Connection, target: Connection): Promise<void>;
  generateDDL(table: Table, dialect: string): Promise<string>;
}
```

## 关联组件
1. DBConnector - 数据库连接器
2. DialectConverter - 方言转换器
3. SchemaMigrator - 结构迁移工具
4. TypeMapper - 数据类型映射器

## 操作流程
1. 配置数据库连接参数
2. 建立数据库连接
3. 执行结构分析或迁移
4. 生成适配目标数据库的DDL
5. 验证转换结果
