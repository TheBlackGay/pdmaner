# 数据类型管理模块

## 功能描述
- 统一管理基础数据类型与数据域
- 支持自定义复合类型定义
- 提供跨数据库类型映射

## 代码架构
```bash
代码入口：src/app/container/datatype
页面组件：src/components/select
关联模块：数据表管理、字段管理
```

## 核心功能点
1. 类型定义
   - 基础类型扩展配置
   - 复合类型结构定义
   ```js
   // 自定义类型示例
   const addressType = {
     name: 'Address',
     fields: {
       province: 'string',
       city: 'string',
       detail: 'string'
     }
   }
   ```

2. 类型验证
   - 数据格式校验规则
   - 取值范围限制配置
   ```mermaid
   graph TB
     A[字段类型] --> B{是否自定义类型}
     B -->|是| C[应用验证规则]
     B -->|否| D[使用基础验证]
   ```

3. 数据库适配
   - 多数据库类型映射表
   - 自动类型转换规则
   - 类型兼容性检查

## 接口定义
```typescript
interface DataTypeService {
  createType(typeDef: TypeDefinition): Promise<void>;
  validateValue(type: string, value: any): ValidationResult;
  getMappings(database: string): Promise<TypeMapping[]>;
}
```

## 关联组件
1. TypeDesigner - 类型设计器
2. ValidatorConfig - 验证规则配置器
3. MappingTable - 数据库类型映射表
4. CompatibilityChecker - 类型兼容性检查器

## 操作流程
1. 定义基础/复合数据类型
2. 配置验证规则和映射关系
3. 应用到表字段设计
4. 执行类型兼容性检查
