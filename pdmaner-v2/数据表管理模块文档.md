# 数据表管理模块文档

## 功能描述
- 实现数据表全生命周期管理
- 支持字段/索引/约束的精细化配置
- 提供表结构标准化检查

## 代码架构
```bash
代码入口：src/app/container/table
页面组件：src/components/table
关联模块：ER关系图、数据类型管理
```

## 核心功能点
1. 表结构设计
   - 可视化字段配置
   - 智能类型推导
   ```js
   // 表结构定义示例
   const tableSchema = {
     name: 'User',
     fields: [
       {name: 'id', type: 'uuid', primaryKey: true},
       {name: 'email', type: 'string', unique: true}
     ]
   }
   ```

2. 约束管理
   - 主键/外键配置
   - 唯一性/检查约束
   ```mermaid
   graph TB
     A[创建新表] --> B[添加字段]
     B --> C[配置约束]
     C --> D[生成DDL]
   ```

3. 标准化检查
   - 命名规范验证
   - 类型兼容性检查
   - 索引优化建议

## 接口定义
```typescript
interface TableService {
  createTable(schema: TableSchema): Promise<void>;
  validateTable(schema: TableSchema): ValidationResult;
  generateSQL(schema: TableSchema): Promise<string>;
}
```

## 关联组件
1. TableDesigner - 可视化表设计器
2. ConstraintConfig - 约束条件配置器
3. SchemaValidator - 结构验证工具
4. SQLPreview - SQL语句预览器

## 操作流程
1. 创建新表/导入现有表
2. 配置字段属性
3. 添加索引和约束
4. 执行标准化检查
5. 生成DDL语句
6. 导出或执行SQL
