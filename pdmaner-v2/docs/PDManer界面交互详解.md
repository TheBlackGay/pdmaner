# PDManer界面交互详解

## 1. 用户界面结构

### 1.1 整体布局

PDManer采用现代IDE风格的多区域布局，界面主要分为以下几个区域：

- **标题栏**：位于顶部，显示应用标题、当前项目名称和窗口控制按钮
- **主工具栏**：位于标题栏下方，包含常用操作按钮（新建、打开、保存等）和功能模块切换按钮
- **左侧资源面板**：显示项目资源树，包括实体、关系图、数据字典等分类节点
- **主编辑区**：中央区域，采用多标签页设计，支持同时打开多个编辑内容
- **右侧属性面板**：显示当前选中对象的属性，支持属性编辑
- **底部状态栏**：显示操作状态、提示信息和进度指示器

整体布局采用响应式设计，各区域可以调整大小或折叠/展开，提高空间利用率。布局结构在`src/app/main/index.js`中实现，使用Flex布局确保各个区域比例合理且可调整。

### 1.2 主要页面组成

#### 1.2.1 欢迎页面

欢迎页面(`src/app/welcome/index.js`)是用户启动应用时首先看到的界面，包含以下元素：

- **项目模板区**：提供空白项目和各种预设模板
- **最近项目列表**：显示最近打开的项目，包含缩略图、名称和日期
- **快速操作区**：包含新建项目、打开项目、导入项目等按钮
- **版本和帮助信息**：显示当前版本和帮助链接

#### 1.2.2 主编辑界面

主编辑界面(`src/app/main/index.js`)是用户进行数据库建模的主要工作区，具有以下特点：

- **多标签页设计**：支持同时打开多个编辑对象，通过标签切换
- **上下文相关工具栏**：根据当前编辑内容动态显示相关工具按钮
- **分割视图**：在某些编辑模式下支持垂直或水平分割视图

#### 1.2.3 ER图设计界面

ER图设计界面(`src/app/container/relation/index.js`)用于可视化设计实体关系模型：

- **绘图画布**：基于@antv/x6实现的交互式绘图区域
- **工具面板**：包含实体表、关联线等绘图元素
- **缩略图**：提供整体视图导航
- **缩放控制**：支持画布缩放、适应视图等操作

#### 1.2.4 实体编辑界面

实体编辑界面(`src/app/container/entity/index.js`)用于编辑单个实体的详细属性：

- **基本信息区**：编辑实体名称、代码、注释等基本属性
- **字段列表**：以表格形式管理实体的字段定义
- **索引管理**：管理实体的索引定义
- **代码预览**：实时预览生成的SQL代码

#### 1.2.5 数据字典界面

数据字典界面(`src/app/container/dict/index.js`)用于管理数据字典和代码值：

- **字典列表**：管理多个数据字典
- **字典项编辑**：编辑单个字典的项目列表
- **导入导出功能**：支持字典数据的导入导出

#### 1.2.6 代码生成界面

代码生成界面(`src/app/container/tools/codeGenerator.js`)用于配置和执行代码生成：

- **模板选择**：选择代码生成模板
- **参数配置**：设置代码生成的各种参数
- **输出目录设置**：指定生成文件的目标位置
- **生成进度指示**：显示代码生成的进度和结果

### 1.3 组件层次关系

PDManer的UI组件采用层次化组织结构，主要分为以下层次：

1. **页面级组件**：如Welcome、Main等顶层页面组件
2. **容器组件**：如Entity、Relation、Dict等功能模块容器
3. **复合组件**：如ErCanvas、TableEditor等具有复杂功能的独立组件
4. **基础UI组件**：如Button、Modal、Input、Select等通用UI组件

组件间通信方式：
- **父子组件**：通过props传递数据和回调函数
- **全局状态**：通过Redux store共享应用状态
- **事件系统**：使用自定义事件机制实现复杂组件间通信

组件层次结构示例：
```
App
├── Welcome
│   └── ProjectList
│       └── ProjectCard
└── Main
    ├── Sidebar
    │   └── ResourceTree
    ├── TabsContainer
    │   ├── EntityContainer
    │   │   ├── EntityBase
    │   │   ├── EntityFields
    │   │   └── EntityIndexes
    │   ├── RelationContainer
    │   │   └── ErCanvas
    │   └── DictContainer
    └── PropertiesPanel
```

## 2. 核心交互流程

### 2.1 项目管理流程

项目管理是PDManer的基础功能，其交互流程如下：

#### 2.1.1 创建新项目

1. 用户点击欢迎页面中的"新建项目"按钮
2. 系统打开新建项目对话框
3. 用户填写项目名称、选择默认数据库类型、指定保存位置
4. 用户点击"创建"按钮
5. 系统创建空项目文件并打开主编辑界面
6. 系统自动创建默认的关系图和初始配置

#### 2.1.2 打开已有项目

1. 用户点击欢迎页面中的"打开项目"按钮或选择最近项目列表中的项目
2. 如点击"打开项目"，系统弹出文件选择对话框
3. 用户选择`.pdma.json`项目文件
4. 系统加载项目文件并解析
5. 系统打开主编辑界面，并在资源树中显示项目内容
6. 系统恢复上次编辑状态（如打开的标签页）

#### 2.1.3 保存项目

1. 用户编辑项目后点击工具栏中的"保存"按钮
2. 如是新项目未保存过，系统弹出保存对话框
3. 用户指定保存位置和文件名
4. 系统将项目数据序列化为JSON格式
5. 系统将JSON数据写入文件
6. 系统更新标题栏显示和最近项目列表

### 2.2 实体设计流程

实体设计是数据库建模的核心，交互流程如下：

#### 2.2.1 创建新实体

1. 用户在资源树中右键点击"实体"节点，选择"新建实体"
2. 系统弹出新建实体对话框
3. 用户填写实体名称、代码和注释
4. 用户点击"确定"按钮
5. 系统创建实体对象并添加到项目中
6. 系统在主编辑区打开实体编辑标签页

#### 2.2.2 编辑实体字段

1. 用户在实体编辑页面中的字段列表区域点击"添加"按钮
2. 系统添加一行新字段
3. 用户编辑字段的名称、类型、长度等属性
4. 系统实时验证输入并提供智能提示
5. 用户可通过拖拽调整字段顺序
6. 系统实时更新实体数据模型

#### 2.2.3 管理索引

1. 用户切换到实体编辑页面的"索引"标签
2. 用户点击"添加"按钮创建新索引
3. 系统弹出索引编辑对话框
4. 用户设置索引名称、类型，并选择包含的字段
5. 用户点击"确定"按钮
6. 系统添加索引到实体并更新显示

### 2.3 关系图设计流程

关系图设计提供了数据模型的可视化表示，交互流程如下：

#### 2.3.1 创建关系图

1. 用户在资源树中右键点击"关系图"节点，选择"新建关系图"
2. 系统弹出新建关系图对话框
3. 用户填写关系图名称和注释
4. 用户点击"确定"按钮
5. 系统创建空关系图并打开关系图编辑标签页

#### 2.3.2 添加实体到关系图

1. 用户在关系图编辑页面左侧的实体列表中找到目标实体
2. 用户将实体拖拽到画布上
3. 系统在画布上创建实体表图形
4. 用户可以调整实体表的位置和大小
5. 系统自动排列实体表的字段显示

#### 2.3.3 创建实体关系

1. 用户点击关系图工具栏中的"关系线"工具
2. 用户点击源实体表上的连接点
3. 用户拖动到目标实体表的连接点
4. 系统创建关系连线
5. 系统弹出关系属性对话框
6. 用户设置关系类型（一对一、一对多等）
7. 用户点击"确定"按钮
8. 系统更新关系线的样式和标记

### 2.4 代码生成流程

代码生成将数据模型转换为实际的数据库脚本或应用代码，交互流程如下：

#### 2.4.1 SQL脚本生成

1. 用户点击工具栏中的"生成SQL"按钮
2. 系统弹出SQL生成配置对话框
3. 用户选择目标数据库类型、输出文件路径和生成选项
4. 用户点击"生成"按钮
5. 系统基于数据模型生成SQL脚本
6. 系统显示生成结果并提供预览
7. 用户可选择保存或复制生成的SQL

#### 2.4.2 文档生成

1. 用户点击工具栏中的"生成文档"按钮
2. 系统弹出文档生成配置对话框
3. 用户选择文档类型（HTML、Word、PDF等）和输出选项
4. 用户点击"生成"按钮
5. 系统处理数据模型并生成文档
6. 系统打开生成的文档或显示保存位置

#### 2.4.3 代码生成

1. 用户点击工具栏中的"代码生成"按钮
2. 系统弹出代码生成配置对话框
3. 用户选择代码模板、包名、输出路径等配置
4. 用户点击"生成"按钮
5. 系统根据模板和数据模型生成代码文件
6. 系统显示生成进度和结果摘要
7. 用户可选择在文件管理器中打开生成目录

## 3. 用户操作实现

### 3.1 鼠标操作

PDManer支持丰富的鼠标交互操作，主要包括：

#### 3.1.1 点击和选择

- **单击**：选择单个对象（实体、字段、关系线等）
- **Ctrl+点击**：多选模式，添加或移除选中项
- **双击**：
  - 在资源树中双击项目，打开对应编辑界面
  - 在关系图中双击实体，打开实体编辑界面
  - 在字段列表中双击单元格，进入编辑模式

#### 3.1.2 拖拽操作

- **移动元素**：在关系图中拖动实体表改变位置
- **调整大小**：拖动实体表边缘或角落调整大小
- **创建关系**：从一个实体连接点拖动到另一个实体创建关系
- **排序**：在字段列表中上下拖动调整字段顺序
- **资源管理**：拖动资源树中的节点调整组织结构

#### 3.1.3 右键菜单

PDManer在不同上下文中提供了丰富的右键菜单：

- **资源树右键菜单**：包含新建、重命名、删除等操作
- **关系图右键菜单**：包含复制、粘贴、对齐、分布等操作
- **实体表右键菜单**：包含编辑实体、添加字段、创建索引等操作
- **字段右键菜单**：包含编辑、删除、上移下移等操作

右键菜单的实现位于`src/lib/contextMenuUtil.js`，根据不同上下文动态生成菜单项。

### 3.2 键盘操作

PDManer支持多种键盘快捷键提高操作效率：

#### 3.2.1 通用快捷键

- **Ctrl+N**：新建项目
- **Ctrl+O**：打开项目
- **Ctrl+S**：保存当前项目
- **Ctrl+Shift+S**：项目另存为
- **Ctrl+Z**：撤销操作
- **Ctrl+Y**：重做操作

#### 3.2.2 编辑快捷键

- **Ctrl+C**：复制选中内容
- **Ctrl+V**：粘贴内容
- **Ctrl+X**：剪切选中内容
- **Delete**：删除选中内容
- **Tab**：在编辑区域内字段切换
- **Shift+Tab**：反向切换字段

#### 3.2.3 关系图快捷键

- **Ctrl+鼠标滚轮**：缩放画布
- **空格+拖拽**：平移画布
- **Ctrl+A**：选择所有元素
- **Ctrl+G**：组合选中元素
- **Ctrl+Shift+G**：解除组合

键盘事件的处理位于各组件的事件监听器中，例如`src/components/ercanvas/index.js`中处理关系图的键盘事件。

### 3.3 表单操作

PDManer中的表单操作主要集中在实体、字段、索引等对象的属性编辑上：

#### 3.3.1 输入控件

- **文本输入**：使用Input组件，支持即时验证
- **下拉选择**：使用Select组件，提供预定义选项
- **复选框**：用于布尔属性（如"是否主键"）
- **数字输入**：用于长度、精度等数值属性
- **日期选择器**：用于日期类型的默认值设置

#### 3.3.2 表格编辑

字段列表和索引列表使用表格形式编辑：

- **行内编辑**：直接在表格中编辑单元格
- **批量操作**：支持多选后的批量删除、修改
- **快速填充**：自动补全和推荐功能
- **键盘导航**：使用方向键在单元格间导航

#### 3.3.3 表单验证

PDManer实现了全面的表单验证机制：

- **即时验证**：用户输入时即时验证
- **提交验证**：表单提交前验证所有字段
- **错误提示**：在表单控件旁直接显示错误信息
- **正则表达式**：使用正则表达式验证格式（如命名规范）

表单组件的实现位于`src/components/form`目录，表单验证逻辑位于`src/lib/validate_util.js`。

### 3.4 拖拽操作

拖拽是PDManer中的核心交互方式，实现了多种拖拽场景：

#### 3.4.1 元素拖拽

- **实体拖放**：从资源面板拖放实体到关系图
- **工具拖放**：从工具面板拖放元素（如新实体、注释框）到关系图
- **位置调整**：拖动调整关系图中元素的位置

#### 3.4.2 调整大小

- **实体表缩放**：拖动边缘或角落调整实体表大小
- **分割面板调整**：拖动分隔条调整面板大小
- **列宽调整**：拖动表格列头调整列宽

#### 3.4.3 排序拖拽

- **字段排序**：上下拖动调整字段顺序
- **索引字段排序**：调整索引中字段的顺序
- **标签排序**：拖动标签页调整顺序

拖拽功能主要通过以下两种方式实现：

1. **原生HTML5拖放API**：用于简单的拖放场景
2. **第三方库**：
   - SortableJS：用于列表排序
   - @antv/x6提供的拖放插件：用于关系图元素拖放

拖拽实现的核心代码位于`src/components/ercanvas/index.js`和`src/lib/drag_util.js`。

## 4. 状态反馈机制

### 4.1 操作反馈

PDManer通过多种方式为用户操作提供即时反馈：

#### 4.1.1 视觉反馈

- **高亮效果**：选中对象时添加高亮边框
- **悬停效果**：鼠标悬停在可操作元素上显示提示性视觉效果
- **动画过渡**：操作执行时使用平滑过渡动画
- **焦点指示**：当前焦点元素有明显的视觉标识

#### 4.1.2 状态指示

- **工具按钮状态**：禁用不可用的按钮，选中当前激活的工具
- **光标变化**：根据当前操作模式改变光标形状
- **拖拽状态**：拖拽过程中显示可拖放区域和效果预览
- **编辑状态**：未保存的内容使用特殊标记（如标签页上的星号）

#### 4.1.3 音效反馈

- **操作确认音**：成功完成操作时的提示音
- **警告音**：遇到错误或警告时的提示音
- **进度音效**：长时间操作的进度提示音

音效反馈是可选的，用户可在设置中启用或禁用。

### 4.2 错误提示

PDManer采用多层次的错误提示机制：

#### 4.2.1 内联错误提示

- **表单校验**：输入框下方直接显示错误信息
- **字段错误**：在字段列表中标记错误的字段
- **语法错误**：在代码编辑器中标记语法错误

#### 4.2.2 对话框提示

- **错误对话框**：操作失败时显示错误对话框
- **确认对话框**：危险操作前请求用户确认
- **警告对话框**：潜在问题的警告提示

#### 4.2.3 状态栏提示

- **临时提示**：短期错误信息在状态栏显示
- **操作结果**：操作结果的简短反馈
- **链接提示**：包含查看详情链接的错误提示

错误处理实现位于`src/lib/error_util.js`，UI层面的错误提示组件位于`src/components/message`目录。

### 4.3 进度指示

PDManer对耗时操作提供多种进度反馈机制：

#### 4.3.1 加载指示器

- **全局加载**：覆盖整个应用的半透明加载屏
- **区域加载**：仅覆盖特定区域的加载指示器
- **按钮加载**：按钮内的加载动画指示器

#### 4.3.2 进度条

- **确定性进度条**：显示明确百分比的进度条
- **不确定进度条**：用于无法确定进度的操作
- **分段进度条**：多阶段操作的分段进度显示

#### 4.3.3 任务状态

- **任务列表**：显示后台任务执行状态
- **状态通知**：任务完成时的桌面通知
- **历史记录**：已完成任务的历史记录和结果

进度指示器的实现位于`src/components/loading`目录，进度追踪逻辑位于`src/lib/progress_util.js`。

## 5. 可访问性与用户体验

### 5.1 交互一致性

PDManer通过以下方式保持交互一致性：

#### 5.1.1 操作模式一致性

- **创建操作**：所有创建操作使用相似的流程和对话框
- **编辑操作**：统一的编辑模式和确认方式
- **删除操作**：一致的删除确认和撤销机制
- **选择操作**：统一的选择、多选和取消选择方式

#### 5.1.2 视觉一致性

- **色彩系统**：使用一致的色彩主题和色彩语义
- **图标系统**：统一风格的图标设计
- **布局规则**：在不同界面中保持相似的布局模式
- **排版系统**：统一的字体、尺寸和行距

#### 5.1.3 术语一致性

- **命名约定**：使用一致的功能和对象命名
- **提示信息**：使用统一风格的提示和帮助文本
- **错误信息**：错误信息的表述方式保持一致
- **文档同步**：界面术语与帮助文档保持同步

交互一致性的设计指导位于`src/style/theme.js`和`src/lib/constants.js`中定义的公共样式和常量。

### 5.2 视觉层次

PDManer通过视觉设计建立清晰的界面层次结构：

#### 5.2.1 视觉优先级

- **重要元素突出**：关键操作和内容具有更高的视觉权重
- **分组与分隔**：使用视觉分组将相关元素组织在一起
- **层次导航**：面包屑、标签页等提供明确的层次导航
- **焦点引导**：视觉设计引导用户注意当前任务相关内容

#### 5.2.2 信息密度

- **渐进呈现**：根据用户需求逐步呈现复杂信息
- **折叠面板**：使用折叠面板控制信息密度
- **工具提示**：通过悬停显示附加信息
- **上下文菜单**：通过右键菜单提供上下文相关操作

#### 5.2.3 状态区分

- **交互状态**：明确区分默认、悬停、活动、禁用等状态
- **系统状态**：清晰表达系统处于编辑、预览、只读等状态
- **数据状态**：区分数据的新建、修改、已保存等状态

视觉层次的实现位于`src/style`目录中的CSS文件和组件级样式定义。

### 5.3 响应性设计

PDManer针对不同设备和窗口尺寸提供响应式体验：

#### 5.3.1 布局适应

- **弹性布局**：使用Flex和Grid实现弹性布局
- **面板折叠**：在窄屏环境自动折叠侧边面板
- **自适应表格**：表格列宽根据内容和可用空间自动调整
- **内容重排**：在小尺寸窗口中重排内容优化显示

#### 5.3.2 交互适应

- **触摸支持**：为触摸操作优化的交互尺寸和行为
- **输入替代**：为不同输入方式提供替代操作方式
- **快捷操作**：在限制视图中提供快捷访问关键功能的方式

#### 5.3.3 性能优化

- **延迟加载**：非必要内容延迟加载
- **虚拟滚动**：大数据列表使用虚拟滚动提升性能
- **按需渲染**：只渲染当前视口中的复杂组件
- **图形优化**：根据设备性能调整图形渲染细节

响应式设计的实现位于组件的媒体查询样式和自适应布局逻辑中，核心代码在`src/style/responsive.less`和各组件的样式文件中。
