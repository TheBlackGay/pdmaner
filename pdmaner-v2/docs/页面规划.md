# PDManer V2 页面规划文档

## 整体布局

### 项目入口页面布局
```
+------------------+------------------------------------------+
|    顶部标题栏     |                                          |
+------------------+------------------------------------------+
|                  |                                          |
| 项目导航侧栏      |            项目展示区域                    |
| - 全部项目       |     - 最近打开项目（卡片式布局）             |
| - 操作手册       |     - 项目模板                            |

|                  |                                          |
+------------------+------------------------------------------+
```

```
+------------------+------------------------------------------+
|      顶部导航栏   |                                          |
+------------------+------------------------------------------+
```

## 页面结构

### 1. 项目入口页面 (/)
- 功能：
  - 项目管理中心
  - 项目模板管理
  - 快速访问入口
- 布局：
  - 左侧导航栏
    - 全部项目（默认选中）
    - 操作手册
    - 官方网站
  - 主内容区
    - 搜索栏（项目名称/描述搜索）
    - 最近打开项目区域
      - 项目卡片列表
      - 新建项目按钮
    - 项目模板区域
      - 模板卡片列表
- 交互：
  - 新建项目
    - 点击新建按钮
    - 选择项目模板
    - 填写项目信息
  - 打开项目
    - 点击项目卡片直接打开
    - 通过文件系统打开
  - 项目搜索
    - 实时搜索
    - 支持模糊匹配
  - 项目模板
    - 预设模板快速使用
    - 支持自定义模板

### 2. 项目工作台 (/project/:id)
- 功能：项目的主要工作区域
- 布局：
  ```
  +----------------+------------------------------------------+
  |    返回按钮    |        工具栏（保存/撤销/重做等）          |
  |    项目名称    |        搜索框                            |
  +----------------+------------------------------------------+
  |                |                                          |
  |   模块导航栏    |                                          |
  | - 数据表管理    |                                          |
  | - 数据表列表    |            主内容区域                     |
  | - 视图管理      |                                          |
  | - 数据字典      |                                          |
  | - 数据类型管理   |                                          |
  | - 代码生成      |                                          |
  |                |                                          |
  +----------------+------------------------------------------+
  ```

- 顶部工具栏：
  - 文件操作
    - 保存项目 (Ctrl/Command + S)
    - 撤销/重做
    - 导入/导出
  - 视图控制
    - 全屏切换 (Ctrl/Command + Shift + U)
    - 显示/隐藏导航栏 (Ctrl/Command + M)
    - 自动布局 (Ctrl/Command + 拖动鼠标)
  - 搜索功能
    - 全局搜索框
    - 支持表名/字段名搜索

- 左侧导航栏：
  - 数据表管理
    - 表分组管理
    - 表列表展示
    - 新建表功能
  - 视图管理
    - 视图列表
    - 新建视图
  - 数据字典
    - 字典分类
    - 字典项管理
  - 数据类型管理
    - 系统类型
    - 自定义类型
  - 代码生成
    - 模板管理
    - 生成配置

- 快捷键支持：
  - 保存：Ctrl/Command + S
  - 全屏：Ctrl/Command + Shift + U
  - 导航栏：Ctrl/Command + M
  - 关系图：Ctrl/Command + F
  - 自动布局：Ctrl/Command + 拖动

- 状态管理：
  - 项目配置信息
  - 当前编辑状态
  - 撤销/重做历史
  - 自动保存功能

- 交互特性：
  - 模块间快速切换
  - 拖拽调整布局
  - 右键菜单支持
  - 实时保存
  - 操作历史记录

### 3. 数据表管理 (/project/:id/table)
#### 3.1 表结构编辑界面
- 布局：
  ```
  +----------------+------------------------------------------+
  |   表基本信息    |           工具栏                         |
  |   代码/显示名称  |  保存 刷新 撤销 重做 快捷工具 设置        |
  +----------------+------------------------------------------+
  |                |           标签页导航                      |
  |                |  数据表 索引 代码 规则检查                 |
  |                +------------------------------------------+
  |                |           字段设计表格                    |
  |                |                                          |
  |                |  序号 字段代码  显示名称  主键  非空  自增  |
  |                |  数据域  数据类型  长度  小数位数          |
  |                |                                          |
  |                |  [+ 增加] [- 删除] [↑ 上移] [↓ 下移]     |
  |                |                                          |
  |                +------------------------------------------+
  |                |           底部信息栏                      |
  |                |  数据库方言：MySQL  创建人  创建时间       |
  +----------------+------------------------------------------+
  ```

- 顶部工具栏：
  - 基本操作
    - 保存 (Ctrl/Command + S)
    - 刷新
    - 撤销 (Ctrl/Command + Z)
    - 重做 (Ctrl/Command + Shift + Z)
  - 快捷工具
    - 字段模板
    - 批量编辑
    - 导入/导出
  - 设置
    - 显示选项
    - 数据库方言
    - 命名规范

- 标签页功能：
  - 数据表
    - 字段设计
    - 字段排序
    - 批量操作
  - 索引管理
    - 索引列表
    - 索引字段选择
  - 代码管理
    - DDL预览
    - 代码生成配置
  - 规则检查
    - 命名规范检查
    - 设计规范检查

- 字段设计表格：
  - 基础列：
    - 序号（自动生成）
    - 字段代码（英文标识）
    - 显示名称（中文说明）
    - 主键标识（复选框）
    - 非空标识（复选框）
    - 自增标识（复选框）
  - 类型列：
    - 数据域（预设数据域选择）
    - 数据类型（下拉选择）
    - 长度（数值输入）
    - 小数位数（数值输入）
  - 操作列：
    - 增加字段
    - 删除字段
    - 上移字段
    - 下移字段

- 底部信息栏：
  - 数据库方言显示
  - 创建人信息
  - 创建时间
  - 最后修改信息

- 快捷键支持：
  - 表格操作
    - 新增行：Ctrl/Command + Enter
    - 删除行：Ctrl/Command + Delete
    - 上移行：Ctrl/Command + ↑
    - 下移行：Ctrl/Command + ↓
  - 编辑操作
    - 复制字段：Ctrl/Command + C
    - 粘贴字段：Ctrl/Command + V
    - 剪切字段：Ctrl/Command + X
  - 其他操作
    - 保存：Ctrl/Command + S
    - 撤销：Ctrl/Command + Z
    - 重做：Ctrl/Command + Shift + Z

- 交互特性：
  - 单元格编辑
    - 双击编辑
    - Tab键切换
    - Enter确认
  - 智能提示
    - 数据类型自动完成
    - 长度默认值
    - 命名规范提示
  - 拖拽功能
    - 字段排序
    - 表格列宽调整
  - 批量操作
    - 多行选择
    - 批量修改
    - 批量删除

- 数据验证：
  - 字段名称唯一性
  - 数据类型有效性
  - 长度范围检查
  - 必填项检查

### 4. ER图设计器 (/project/:id/er)
- 功能：可视化设计数据库关系
- 布局：
  ```
  +----------------+----------------------------------+
  |   工具栏        |                                 |
  +----------------+           设计画布               |
  |   元素面板      |                                 |
  |                |                                 |
  +----------------+----------------------------------+
  |                     缩略图                        |
  +---------------------------------------------------+
  ```
- 交互：
  - 拖拽创建表
  - 连线创建关系
  - 缩放和平移
  - 自动布局

### 5. 数据库管理 (/project/:id/database)
- 功能：管理数据库连接和同步
- 布局：
  - 连接列表
  - 连接配置表单
  - 数据库同步状态
- 交互：
  - 测试连接
  - 导入现有数据库
  - 同步确认对话框

### 6. 代码生成 (/project/:id/code)
- 功能：生成数据库相关代码
- 布局：
  - 模板选择
  - 配置选项
  - 预览区域
- 交互：
  - 实时预览
  - 批量生成
  - 自定义模板

## 项目相关组件

### 1. 项目卡片组件
- 展示内容：
  - 项目名称
  - 项目图标
  - 最后修改时间
  - 数据库类型图标
- 操作：
  - 点击打开
  - 右键菜单（复制、删除、导出等）

### 2. 新建项目对话框
- 表单内容：
  - 项目名称（必填）
  - 项目描述
  - 数据库类型选择
  - 模板选择
- 功能：
  - 表单验证
  - 模板预览
  - 快速创建

### 3. 项目模板卡片
- 展示内容：
  - 模板名称
  - 模板描述
  - 适用场景
  - 包含表数量
- 操作：
  - 使用模板
  - 预览模板
  - 收藏模板

## 主题和样式

### 1. 配色方案
- 主色：#1890ff
- 成功色：#52c41a
- 警告色：#faad14
- 错误色：#f5222d
- 文字色：#000000d9

### 2. 布局尺寸
- 侧边栏宽度：200px
- 头部高度：64px
- 内容区域内边距：24px

### 3. 响应式断点
- xs: < 576px
- sm: >= 576px
- md: >= 768px
- lg: >= 992px
- xl: >= 1200px
- xxl: >= 1600px
