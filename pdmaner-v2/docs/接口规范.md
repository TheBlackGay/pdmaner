# PDManer V2 接口规范文档

## 通用规范

### 1. 请求格式
- 基础URL：`/api/v1`
- 请求方法：GET, POST, PUT, DELETE
- Content-Type: application/json
- 字符编码：UTF-8

### 2. 响应格式
```typescript
interface ApiResponse<T> {
  code: number;      // 状态码
  message: string;   // 提示信息
  data?: T;         // 响应数据
}
```

### 3. 状态码
- 200: 成功
- 400: 请求参数错误
- 401: 未授权
- 403: 禁止访问
- 404: 资源不存在
- 500: 服务器错误

## 数据结构定义

### 1. 项目相关
```typescript
interface Project {
  id: string;
  name: string;
  description?: string;
  createTime: string;
  updateTime: string;
  lastOpenTime?: string;
  icon?: string;
  database: {
    type: 'MySQL' | 'PostgreSQL' | 'Oracle' | 'SQLServer';
    version?: string;
  };
  template?: string;  // 使用的模板ID
  tables: Table[];
  relations: Relation[];
}

interface ProjectTemplate {
  id: string;
  name: string;
  description: string;
  category: string;
  tags: string[];
  thumbnail?: string;
  tableCount: number;
  tables: Table[];
  relations: Relation[];
  createTime: string;
  updateTime: string;
  isOfficial: boolean;
  author: string;
}

interface Table {
  id: string;
  name: string;
  comment?: string;
  fields: Field[];
  indexes: Index[];
  constraints: Constraint[];
}

interface Field {
  id: string;
  code: string;           // 字段代码（英文名）
  name: string;          // 显示名称（中文名）
  domain?: string;       // 数据域
  type: string;          // 数据类型
  length?: number;       // 长度
  precision?: number;    // 精度
  scale?: number;        // 小数位数
  primaryKey: boolean;   // 主键标识
  nullable: boolean;     // 非空标识
  autoIncrement: boolean; // 自增标识
  defaultValue?: string; // 默认值
  comment?: string;      // 注释
  order: number;        // 排序号
  createUser?: string;   // 创建人
  createTime?: string;   // 创建时间
  updateUser?: string;   // 修改人
  updateTime?: string;   // 修改时间
}

interface Index {
  id: string;
  name: string;
  type: 'UNIQUE' | 'NORMAL' | 'FULLTEXT';
  fields: string[];
}

interface Constraint {
  id: string;
  name: string;
  type: 'PRIMARY' | 'FOREIGN' | 'UNIQUE' | 'CHECK';
  fields: string[];
  refTable?: string;
  refFields?: string[];
}

interface Relation {
  id: string;
  name: string;
  sourceTable: string;
  targetTable: string;
  type: '1:1' | '1:n' | 'n:n';
  fields: {
    source: string[];
    target: string[];
  };
}

interface DataDomain {
  id: string;
  code: string;         // 数据域代码
  name: string;         // 数据域名称
  type: string;         // 默认数据类型
  length?: number;      // 默认长度
  precision?: number;   // 默认精度
  scale?: number;      // 默认小数位
  description?: string; // 描述
  createTime: string;
  updateTime: string;
}
```

### 2. 数据库连接相关
```typescript
interface DatabaseConnection {

  name: string;
  type: 'MySQL' | 'PostgreSQL' | 'Oracle' | 'SQLServer';
```

## API 接口定义

### 1. 项目管理
#### 1.1 获取项目列表
- 请求：GET /api/v1/projects
- 参数：
  ```typescript
  interface ProjectQuery {
    keyword?: string;
    page?: number;
    pageSize?: number;
    sortBy?: 'name' | 'createTime' | 'updateTime' | 'lastOpenTime';
    sortOrder?: 'asc' | 'desc';
  }
  ```
- 响应：`ApiResponse<{ total: number; items: Project[] }>`

#### 1.2 创建项目
- 请求：POST /api/v1/projects
- 参数：
  ```typescript
  interface CreateProject {
    name: string;
    description?: string;
    database: {
      type: 'MySQL' | 'PostgreSQL' | 'Oracle' | 'SQLServer';
      version?: string;
    };
    templateId?: string;  // 使用的模板ID
  }
  ```
- 响应：`ApiResponse<Project>`

#### 1.3 获取最近项目
- 请求：GET /api/v1/projects/recent
- 参数：
  ```typescript
  interface RecentProjectQuery {
    limit?: number;  // 默认 10
  }
  ```
- 响应：`ApiResponse<Project[]>`

#### 1.4 打开项目
- 请求：POST /api/v1/projects/:id/open
- 响应：`ApiResponse<Project>`

#### 1.5 导入项目
- 请求：POST /api/v1/projects/import
- 参数：`multipart/form-data`
- 响应：`ApiResponse<Project>`

#### 1.6 导出项目
- 请求：GET /api/v1/projects/:id/export
- 响应：`application/octet-stream`

#### 1.7 获取项目配置
- 请求：GET /api/v1/projects/:id/config
- 响应：`ApiResponse<ProjectConfig>`

#### 1.8 更新项目配置
- 请求：PUT /api/v1/projects/:id/config
- 参数：`ProjectConfig`
- 响应：`ApiResponse<ProjectConfig>`

#### 1.9 获取项目状态
- 请求：GET /api/v1/projects/:id/status
- 响应：
  ```typescript
  interface ProjectStatus {
    lastSaveTime: string;
    isModified: boolean;
    currentModule: string;
    undoStack: number;
    redoStack: number;
  }
  ```

#### 1.10 获取操作历史
- 请求：GET /api/v1/projects/:id/history
- 参数：
  ```typescript
  interface HistoryQuery {
    page?: number;
    pageSize?: number;
    startTime?: string;
    endTime?: string;
  }
  ```
- 响应：
  ```typescript
  interface OperationHistory {
    id: string;
    type: 'CREATE' | 'UPDATE' | 'DELETE' | 'MOVE' | 'IMPORT' | 'EXPORT';
    target: string;
    detail: string;
    operator: string;
    operateTime: string;
  }
  ```

### 3. 表管理
#### 3.1 获取表列表
- 请求：GET /api/v1/projects/:projectId/tables
- 参数：
  ```typescript
  interface TableQuery {
    keyword?: string;
    group?: string;
    page?: number;
    pageSize?: number;
  }
  ```
- 响应：`ApiResponse<Table[]>`

#### 3.2 创建表
- 请求：POST /api/v1/projects/:projectId/tables
- 参数：
  ```typescript
  interface CreateTable {
    name: string;
    comment?: string;
    group?: string;
    fields: Field[];
    indexes?: Index[];
    constraints?: Constraint[];
  }
  ```
- 响应：`ApiResponse<Table>`

#### 3.3 更新表
- 请求：PUT /api/v1/projects/:projectId/tables/:tableId
- 参数：同 CreateTable
- 响应：`ApiResponse<Table>`

#### 3.4 删除表
- 请求：DELETE /api/v1/projects/:projectId/tables/:tableId
- 响应：`ApiResponse<void>`

#### 3.5 获取表字段
- 请求：GET /api/v1/projects/:projectId/tables/:tableId/fields
- 响应：`ApiResponse<Field[]>`

#### 3.6 批量更新字段
- 请求：PUT /api/v1/projects/:projectId/tables/:tableId/fields
- 参数：`Field[]`
- 响应：`ApiResponse<Field[]>`

#### 3.7 导入表结构
- 请求：POST /api/v1/projects/:projectId/tables/import
- 参数：
  ```typescript
  interface ImportTable {
    type: 'SQL' | 'EXCEL' | 'JSON';
    content: string;
    options?: {
      override?: boolean;
      ignoreError?: boolean;
    };
  }
  ```
- 响应：`ApiResponse<{ success: boolean; tables: Table[]; errors?: string[] }>`

#### 3.8 导出表结构
- 请求：POST /api/v1/projects/:projectId/tables/export
- 参数：
  ```typescript
  interface ExportTable {
    tables: string[];  // 表ID列表
    type: 'SQL' | 'EXCEL' | 'JSON';
    options?: {
      dialect?: string;
      includeData?: boolean;
    };
  }
  ```
- 响应：`ApiResponse<{ content: string }>`

#### 3.9 获取表索引
- 请求：GET /api/v1/projects/:projectId/tables/:tableId/indexes
- 响应：`ApiResponse<Index[]>`

#### 3.10 更新表索引
- 请求：PUT /api/v1/projects/:projectId/tables/:tableId/indexes
- 参数：`Index[]`
- 响应：`ApiResponse<Index[]>`

#### 3.11 获取表约束
- 请求：GET /api/v1/projects/:projectId/tables/:tableId/constraints
- 响应：`ApiResponse<Constraint[]>`

#### 3.12 更新表约束
- 请求：PUT /api/v1/projects/:projectId/tables/:tableId/constraints
- 参数：`Constraint[]`
- 响应：`ApiResponse<Constraint[]>`

#### 3.13 验证表结构
- 请求：POST /api/v1/projects/:projectId/tables/:tableId/validate
- 响应：
  ```typescript
  interface ValidationResult {
    valid: boolean;
    errors: {
      field: string;
      message: string;
    }[];
    warnings: {
      field: string;
      message: string;
    }[];
  }
  ```

#### 3.14 获取数据域列表
- 请求：GET /api/v1/domains
- 参数：
  ```typescript
  interface DomainQuery {
    keyword?: string;
    page?: number;
    pageSize?: number;
  }
  ```
- 响应：`ApiResponse<DataDomain[]>`

#### 3.15 字段排序
- 请求：PUT /api/v1/projects/:projectId/tables/:tableId/fields/order
- 参数：
  ```typescript
  interface FieldOrder {
    fieldIds: string[];  // 字段ID列表，按新顺序排列
  }
  ```
- 响应：`ApiResponse<void>`

#### 3.16 批量更新字段
- 请求：PUT /api/v1/projects/:projectId/tables/:tableId/fields/batch
- 参数：
  ```typescript
  interface BatchUpdateFields {
    fields: {
      id: string;
      updates: Partial<Field>;
    }[];
  }
  ```
- 响应：`ApiResponse<Field[]>`

#### 3.17 应用数据域
- 请求：POST /api/v1/projects/:projectId/tables/:tableId/fields/:fieldId/apply-domain
- 参数：
  ```typescript
  interface ApplyDomain {
    domainId: string;
    overwrite?: boolean;  // 是否覆盖现有值
  }
  ```
- 响应：`ApiResponse<Field>`

#### 3.18 验证字段名称
- 请求：POST /api/v1/projects/:projectId/tables/:tableId/fields/validate-name
- 参数：
  ```typescript
  interface ValidateFieldName {
    fieldId?: string;    // 现有字段ID（更新时）
    code: string;        // 字段代码
    name: string;        // 显示名称
  }
  ```
- 响应：
  ```typescript
  interface ValidationResult {
    valid: boolean;
    errors?: {
      field: string;
      message: string;
    }[];
  }
  ```
