# PDManer 交互逻辑文档

## 1. 项目概述

PDManer是一个专业的数据库建模工具，基于Electron框架开发的跨平台桌面应用，使用React、Redux等前端技术构建用户界面。该工具允许用户创建、编辑和管理数据库模型，并能生成相应的SQL代码。

## 2. 技术栈

- **前端框架**: React 16.8.6
- **状态管理**: Redux 4.0.4, Redux-Thunk 2.3.0
- **桌面框架**: Electron 13.1.7
- **图形可视化**: @antv/x6 1.18.3
- **代码编辑**: React-Ace 9.4.1
- **国际化**: 自定义实现(FormatMessage组件)
- **其他工具库**: Lodash, Moment, numeral等

## 3. 应用架构

### 3.1 目录结构

```
- src/
  - actions/       # Redux actions
    - common/      # 通用actions
    - config/      # 配置相关actions
    - core/        # 核心功能actions
  - app/           # 应用组件
    - container/   # 容器组件
    - home/        # 首页组件
    - main/        # 主应用组件
    - welcome/     # 欢迎页面组件
  - components/    # 通用UI组件
  - lang/          # 国际化语言文件
  - lib/           # 工具库和辅助函数
  - reducers/      # Redux reducers
  - style/         # 全局样式
  - index.js       # 前端入口文件
  - main.js        # Electron主进程文件
```

### 3.2 应用生命周期

1. 应用启动时，`main.js`初始化Electron主进程
2. 主进程创建渲染进程，加载`index.html`
3. 渲染进程执行`index.js`，初始化React应用
4. 渲染进程创建Redux Store，挂载Root组件
5. 首次渲染显示Welcome页面，加载用户配置
6. 根据用户操作，进入主应用界面或执行其他功能

## 4. 核心交互流程

### 4.1 启动流程

```
Electron应用启动
  ↓
创建主窗口(createWindow)
  ↓
加载React应用
  ↓
初始化Redux Store
  ↓
渲染Welcome组件
  ↓
读取用户配置(getUserConfigData)
  ↓
检查更新(getVersion/compareVersion)
  ↓
显示主界面或打开上次项目
```

### 4.2 项目操作流程

#### 4.2.1 创建项目

```
用户点击"创建项目"
  ↓
调用createProject action
  ↓
打开文件保存对话框
  ↓
保存项目文件(saveJsonPromise)
  ↓
更新项目历史记录(addHistory)
  ↓
加载空项目模板(emptyProject)
  ↓
更新Redux状态(CREATE_PROJECT_SUCCESS)
  ↓
进入主编辑界面
```

#### 4.2.2 打开项目

```
用户点击"打开项目"
  ↓
调用openProject action
  ↓
打开文件选择对话框
  ↓
读取项目文件(readJsonPromise)
  ↓
更新项目历史记录(updateHistory)
  ↓
更新Redux状态(READ_PROJECT_SUCCESS)
  ↓
进入主编辑界面
```

#### 4.2.3 保存项目

```
用户点击"保存项目"
  ↓
调用saveProject action
  ↓
检查是否为新项目
  ↓
是 → 调用saveJsonPromiseAs打开保存对话框
否 → 直接调用saveJsonPromise保存
  ↓
更新Redux状态(SAVE_PROJECT_SUCCESS)
  ↓
显示保存成功提示
```

### 4.3 编辑器交互

#### 4.3.1 模型编辑

主界面使用@antv/x6库实现图形化编辑器，支持以下交互：

- 创建/编辑数据表
- 拖拽调整表位置
- 创建表关系连线
- 缩放/平移画布视图
- 导入/导出数据
- 代码生成

#### 4.3.2 上下文菜单

使用ContextMenu组件实现右键菜单功能，支持对象级操作：

- 表操作(添加、删除、复制等)
- 字段操作(添加、编辑、删除等)
- 索引操作
- 关系操作

## 5. 通信机制

### 5.1 Electron进程通信

主进程与渲染进程通过IPC通信：

```
ipcMain.on("jarPath", (event) => {...})      // 获取Java组件路径
ipcMain.on("template", (event, {ext, name}) => {...})  // 获取模板文件
ipcMain.on("loadFile", (event, args) => {...})  // 加载文件
ipcMain.on("update", () => {...})  // 检查更新
ipcMain.on("data", (e, args) => {...})  // 数据传输
```

### 5.2 React组件通信

- 父子组件：Props传递
- 全局状态：Redux Store
- 上下文共享：React Context(ConfigContent)
- 事件机制：自定义Event系统(event_tool.js)

## 6. 状态管理

### 6.1 Redux Store结构

```
{
  config: {             // 用户配置
    language: String,   // 当前语言
    history: Array,     // 项目历史记录
    ...
  },
  core: {               // 核心项目数据
    data: Object,       // 当前项目数据
    info: String,       // 项目路径
    ...
  },
  common: {             // 通用状态
    loading: Boolean,   // 加载状态
    status: String,     // 应用状态
    ...
  }
}
```

### 6.2 主要Actions

- **core**
  - openProject: 打开项目
  - createProject: 创建项目
  - saveProject: 保存项目
  - updateProject: 更新项目
  - closeProject: 关闭项目
  - removeProject: 删除项目

- **config**
  - getUserConfigData: 获取用户配置
  - saveUserConfig: 保存用户配置
  - addHistory: 添加历史记录
  - removeHistory: 删除历史记录

- **common**
  - openLoading: 显示加载中
  - closeLoading: 关闭加载中
  - optReset: 重置操作状态

## 7. 文件操作

应用通过src/lib/middle.js中定义的函数与本地文件系统交互：

- saveJsonPromise: 保存JSON文件
- readJsonPromise: 读取JSON文件
- openProjectFilePath: 打开项目文件路径
- ensureDirectoryExistence: 确保目录存在
- fileExists: 检查文件是否存在
- deleteFile: 删除文件

## 9. 错误处理

应用实现了全局错误捕获机制：

```javascript
// index.js中的错误处理
class Container extends React.Component{
  componentDidCatch(error) {
    writeLog(error).then((file) => {
      Modal.error({
        title: '出错了',
        message: <span>
          程序出现异常，请前往日志文件查看出错日志：<a onClick={() => showErrorLogFolder(file)}>{file}</a>
        </span>,
      });
    });
  }
  // ...
}
```

此外，应用还实现了项目自动备份功能，防止数据丢失。

## 10. 更新机制

应用使用electron-updater实现自动更新：

```javascript
// main.js中的更新逻辑
autoUpdater.setFeedURL('http://chiner-release.httpchk.com');
autoUpdater.on('download-progress', function (progressObj) {
  win.webContents.send('updateProgress', progressObj);
  win.setProgressBar(progressObj.percent / 100);
})
autoUpdater.on('update-downloaded', function () {
  win.setProgressBar(-1);
  autoUpdater.quitAndInstall();
})
```
