# 数据字典模块文档

## 功能描述
- 实现代码映射表与字段的智能关联
- 支持多层级数据字典结构管理
- 提供字段枚举值的动态绑定

## 代码架构
```bash
代码入口：src/app/container/dict
页面组件：src/components/table
关联模块：数据表管理、字段管理
```

## 核心功能点
1. 字典管理
   - 树形结构字典分类
   - 多语言字典值支持
   ```js
   // 数据字典结构示例
   const dictSchema = {
     code: 'USER_STATUS',
     items: [
       {value: 1, label: '激活', en: 'Active'},
       {value: 0, label: '禁用', en: 'Disabled'}
     ]
   }
   ```

2. 字段关联
   - 自动匹配字段类型
   - 动态值域绑定
   ```mermaid
   graph LR
     A[数据字典] --> B{字段类型匹配}
     B -->|匹配成功| C[自动关联]
     B -->|匹配失败| D[人工配置]
   ```

3. 版本同步
   - 字典变更影响分析
   - 关联字段自动更新通知
   - 历史版本追溯

## 接口定义
```typescript
interface DictionaryService {
  createDictionary(dict: Dictionary): Promise<void>;
  bindField(fieldId: string, dictCode: string): Promise<void>;
  getFieldBindings(fieldId: string): Promise<Dictionary[]>;
}
```

## 关联组件
1. DictTree - 字典树形管理器
2. FieldBinder - 字段绑定配置器
3. ValueEditor - 字典值多语言编辑器
4. ImpactAnalyzer - 变更影响分析面板

## 操作流程
1. 创建/导入数据字典
2. 配置字典层级结构
3. 绑定到表字段
4. 验证字典值应用
5. 管理字典版本变更
